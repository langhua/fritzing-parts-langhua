# 差异图**动画**（规格 · 2026-10-07 用户定 ✓）

> 用户原话 ✓：「每张图本身，能否做成动画效果？动画从 A 图开始，每处变化，先闪烁几次移动的元件和线，
> 然后删除，再显示 B 图闪烁几次对应的元件和线，最后停止闪烁，进入下一处变化。」
>
> 三个口径（用户 2026-10-07 选定 ✓）：
> ① **两个都要** ✓ —— VS Code 界面里能看 ✓，生成的 `.svg` **双击也能自己播** ✓；
> ② **直接做二阶段** ✓ —— 闪的是**元件/导线本体** ✓（不只是标记圈 ✓）；
> ③ **默认节奏** ✓ —— A 闪 2 下 ⇒ B 闪 2 下 ⇒ 停一下 ⇒ 下一处 ✓（每处约 2 秒 ✓），**循环** ✓。

## 为什么能播（两条路一条实现 ✓）

用 **CSS 关键帧**写进 svg 本体 ✓ —— 浏览器里双击会自动播 ✓，
而 VS Code 的 webview 也是同一个引擎 ✓ ⇒ **一份实现同时满足"两个都要"** ✓（✗ 不用各写一套 ✗）。

（✗ 不用 SMIL：Chrome 已弃用 ✓；CSS 动画在 `<img>` 里也会跑 ✓。）

## 关键：怎么给"每个元件/导线"打钥匙 ✓（已量 ✓）

| 对象 | 钥匙 | 证据 |
|---|---|---|
| **零件** ✓ | 渲染出的 `<g partID="…">` ⇔ sketch 实例的 `modelIndex` ✓，关系是 **`partID = modelIndex × 10`** ✓ | 2026-10-07 实测三例逐位相符 ✓：`86333565→863335650` ✓、`90010634→900106340` ✓、`900106760→90010676×10` ✓ |
| **导线** ✓ | 没有 id ✗ ⇒ 按**坐标**精确匹配 ✓（渲染里的 `<line x1,y1,x2,y2>` 就是 **sketch 坐标** ✓，与 sketch 里的 wire geometry 逐位相同 ✓） | 两个渲染器都把线画在绝对 sketch 坐标上 ✓（`render_bb.py` / `render_sch.py` 的出图段 ✓） |
| 覆盖面 | 渲染里**真画出来的**才算 ✓（v40 原理图：59 个实例、只画了 11 个 ✓ —— 核心件取不到 svg 的、`wireFlags` 不含本视图的都不画 ✓，与清单里"已略过"那行**同一口径** ✓） | `_place()` / `probe_partid.py` ✓ |

⇒ 每侧输出 `<g id="a-C1">…</g>` / `<g id="b-C1">…</g>` ✓，id 用**位号唯一 key** ✓（重复位号是 `RC.2` ✓，见 `_seq_keys()` ✓）。

## 动画怎么排 ✓

对**每一处变化** ✓（来源 = 现有的 `pd-<位号>` 记录 ✓）：

```
0.0–0.8s   a-<ref> 闪 2 下（描边/亮度闪 ✓），其余整体压暗到 25% ✓
0.8–1.0s   a-<ref> 淡出 → opacity 0 ✓（这就是"删除 A 的那件" ✓）
1.0–1.8s   b-<ref> 淡入 ✓ 并闪 2 下 ✓
1.8–2.0s   停（保持 B 版 ✓）⇒ 下一处 ✓
```

全部播完 ⇒ **循环** ✓（或在末尾停在 B 版 ✓，二者都行 ✓，做成一个参数 ✓）。

## 分步做法（每步都要**先量后改** ✓）

1. **打钥匙** ✓：`diff_revs.py` 里加一个 `_tag_elements(svg, fzz, view, side)` ✓ —— 把顶层子元素按上表的钥匙包成 `<g id="a-…">` / `<g id="b-…">` ✓；
   自检：**打上钥匙的元素数**必须等于该侧"真画出来"的实例数 ✓（对不上就报错 ✗，别静默少包 ✓）。
2. **生成 CSS** ✓：`_anim_css(refs, timing)` ✓ —— 每处一条 `@keyframes` ✓；`animation-delay` 按序号错开 ✓（**总时长 = 处数 × 2s** ✓）；
   自检：`@keyframes` 条数 == 变化处数 ✓。
3. **接线** ✓：只在**视图**（bb/sch ✓）那条路开 ✓（PCB 那边的"元件"是焊盘/铜片 ✗，打钥匙是另一件事 ✗ ⇒ 先只让 PCB 播**标记圈** ✓，本体动画等以后 ✓）。
4. **验** ✓：
   · `ink_bbox.py`-式的自检：打钥匙数 / keyframes 数 / 处数 三个数要对上 ✓；
   · 真的**打开看一眼**（浏览器双击 + VS Code 里各一次 ✓）—— 动画必须**人的眼睛**判 ✓（§13 规矩 ✓）。

## 已知取舍（写下来免得反复）✓

- 动画让 svg **变大**一些 ✓（每个元素外面多一层 `<g>` + 一段 CSS ✓）；为省体积可以只给**变化处**的元素打钥匙 ✓，没动的**不打** ✓（它们本来就不闪 ✓）—— **默认就这么做** ✓。
- 淡入淡出用 `opacity` ✓ ⇒ 不会动到任何**几何** ✓（AGENTS §13：同一句话能指同一件事 ✓）。
