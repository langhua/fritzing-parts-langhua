## 动画怎么排 ✓

对**每一处变化** ✓（来源 = 现有的 `pd-<位号>` 记录 ✓）：

```
0.0–0.8s   a-<ref> 闪 2 下（opacity 0→1→0→1 ✓）
0.8–1.0s   a-<ref> 淡出 → opacity 0 ✓（这就是"删除 A 的那件" ✓）⇒ **之后一直 0** ✓
1.0–1.8s   b-<ref> 淡入 ✓ 并闪 2 下 ✓
1.8–2.0s   停（保持 B 版 ✓）⇒ 下一处 ✓
```

★ 时间轴**只有一条** ✓：`total = 处数 × 2 s` ✓（✗ 已经没有"收尾段"了 ✗）；每个元素的关键帧
百分比都按**同一条轴**算 ✓（`_anim_css()` 一处算 ✓）。

⇒ 三个时刻（**2026-10-08 定的新口径** ✓）：**进入 = A+B 叠合图**（静 ✓）、
**点了按钮 ⇒ 开局 = A 图** → **中途变过去** → **末态 = B 图**（停住 ✓）。

★ `forwards` ✗ 不能省：不写的话动画一结束元素就**弹回**初始 ✗（A 又全亮 ✓、B 又全灭 ✗）
⇒ 「停在 B」当场作废 ✓。★ 它是**起播时**由 JS 拼进 `animation` 简写的 ✓（见下 ✓），
✗ 不在 svg 里预先写死 ✗。

## 起播：`data-anim` ＋ 界面上的按钮 ✓（2026-10-08 ✓）

```text
svg 里   <g id="a-Wire90013116" data-anim="v100v104-a-8">…</g>
         <svg … data-anim-dur="28.000">          ← 一轮时长（只在 _anim_css 算一处 ✓）
         <style>@keyframes v100v104-a-8{…}</style>
```

按钮（**合并视图「▶ 播放差异」** ✓ / **幻灯片右栏「播放差异」** ✓ —— 文字同名 ✓、记号不同 ✓ ——
两份 HTML ✓，
**同一段脚本** ✓：都由 `replayJs()` 展开 ✓）拿到时长与名字后：

```js
els.forEach(el => el.style.animation = 'none');   // ① 清掉
void document.body.offsetWidth;                   // ② 强制重排
els.forEach(el => el.style.animation =            // ③ 再赋 ⇒ 真的从 0 开始
  el.getAttribute('data-anim') + ' ' + dur + 's linear 1 forwards');
```

★ 为什么要"清 → 重排 → 再赋" ✗：同一条 `animation` **再赋一遍浏览器不会重启动画** ✗
（点了没反应 ✓）—— 这是"点按钮重播"最容易漏的一步 ✓。
