## 1. 元件不许重叠，且要留安全间隔（2026-10-01 用户定）

**规则**：**同一层**（`copper0` / `copper1`，以及各自那一面的丝印 ✓）上的两个元件，
其**画出来的图元**之间的最小净距必须 ≥ **`PART_GAP_MM = 0.25 mm`** ✓；
相交（净距为负）**绝对不许** ✗。

**为什么按"图元 + 层"判，而不是按"件的占位框"或"件的面"**（都有实测依据 ✓）：

| 判据 | 实测后果 ✗ |
|---|---|
| 件的**占位框**（墨迹 bbox） | `NFC_Coil_20mm_6T_0p2_1` 的框是 21.6×22.05 mm（板才 25×25 ✓）⇒ 假报 15/16 个过孔"在元件内" ✗、`LED2` 坐在线圈中间空地也被假报相交 ✗ |
| 只看件的**面** | 线圈**两面都有铜**（`copper0` = 背面那一圈 ✓）⇒ 背面的件压在线圈背面铜上会漏判 ✗ |
| ✓ **逐图元 + 逐层** | 只报真违规 ✓（`C1×U1` 就是这么抓到的：同层只有 −0.340 mm ✗） |

**注意**：**异面**（一正一反）叠着是**正常**的 ✓（背贴电容就贴在 QFN 背后 ✓）——
本板实测 10 对相交里 8 对是这类 ✓，不报 ✓。

**机器守**：`pcb_check.py` 第 **⑧** 条（`PART_GAP_MM` ✓）。

## 2. 过孔不许打在元件内 / 焊盘上，且要留安全距离（2026-10-01 用户定）

用户原话：「我想先实现通孔不能在元件内，并与有安全距离的规则，比如 Via10 在 J1 焊盘上打孔了」✓

- **⑥** 过孔**铜盘**压到**任何**焊盘 ⇒ 违规 ✗（**含同一张网** ✗ = 一般不许 via-in-pad ✗）；
  ★★ **例外（2026-10-01 用户定 ✓）：`EPAD` / 裸露焊盘上的**同网** via-in-pad 是允许的** ✓ ——
  用户原话：「是在 EPAD 上开通孔接 GND 吗？这个必须允许」✓ ——
  QFN 的中央散热盘要接地，业界常规就是在 EPAD 上打一簇过孔接到背面地 ✓；
  ✗ 旧口径把它也当违规 ✗（实测：本项目 `U1.connector20` 正是 EPAD ✓，被 ⑥ 报成“压在盘上”✗）
  ⇒ 等于把正确做法禁掉 ✗。
  ★ 例外**只限 EPAD** ✗（不扩到其它焊盘 ✗）：接插件（`J1`/`J2`）、电阻、电容的盘上
  **仍然禁止打孔** ✗——那才是点名 `Via10` 打在 `J1.connector2` 上那种（机械/装配 ✗）；
  同网的**普通盘**（如 `U1.connector5`）也仍然要留 0.25 mm ✓。
  ★ 判 EPAD 的依据（不猜 ✗）：该焊盘的**连接器名**含 `EPAD`/`EP`/`exposed` ✓
  （本仓实例：`CH32V003F4U6` 的 `connector20 name="EPAD"` ✓、`RT6150` 的 `EP` ✓、`TX-AH` 的 `EPAD1/2` ✓）。
- **⑦** 过孔铜盘与**任何焊盘**、以及**元件画出来的铜**（逐图元 ✓ 含线宽 ✓）的净距
  必须 ≥ **`VIA_SAFE_MM = 0.25 mm`** ✓；
  ★ EPAD 同样例外 ✓：孔**落在 EPAD 框内**不在这里判 ✓（那是合法的 via-in-pad ✓，由 ⑥ 管 ✓）；
    但孔在 EPAD **框外又太近**（< 0.25 mm）⇒ 仍然 FAIL ✗。
  ★ “元件画出来的铜”里要**跳掉焊盘形状** ✗（否则同一颗孔会被 ⑥ 与 ⑦ 重复判 ✗，
    实测 `U1` 的 EPAD 就是这个现象 ✓）；焊盘一律由 ⑥/⑦-焊盘 管 ✓。
- **⑦ 不看丝印** ✓ —— 孔上盖丝印是**印刷**问题 ✓，不是"打在元件上" ✗（实测算进来会多 13 条噪音 ✗）；
- 过孔尺寸口径：`hole size="0.3mm,0.15mm"` = 「**钻孔, 环宽**」⇒ 铜盘 **Ø0.6 mm** ✓。

**量法要按真几何** ✗（两个坑都踩过 ✓）：`<geometry>` 是 **svg 画布原点** ✓，
**真铜心 = geometry + 0.86444 mm**（过孔 ✓）/ **+1.66454 mm**（安装孔 ✓）——
见 `part_box.VIA_DRAW_OFF_MM` ✓（出处 = 用户导出的 `pixel-pcb-v48_图示.svg` ✓）。

**机器守**：`pcb_check.py` 第 **⑥/⑦** 条；
布线时由 `pcb_route.py` 的禁落区**主动躲开** ✓（`VIA_SAFE_MM` / `copper_keep` ✓，
两份实现**互不背书** ✓）。

## 3. 布线不通时，允许把电阻/电容**降一档封装规格**（2026-10-01 用户定）

用户原话：「我建议先把 R1/C1 换成 0402 规格的，减小尺寸。这一条也做成规则吧，
在布线不通的情况下，电阻和电容可以换成小尺寸规格的。当然，C2 是电源电容，不能减小尺寸了吧？」✓

**规则**：

1. **触发条件**：布线器**布不通**（有网连不上 ✓）而**摆位已经无路可退**时，
   允许把 **电阻 / 电容** 换成**更小一档**的封装 ✓ ⟶ 目的 = **腾出走线与过孔的地方** ✓。
2. **降档台阶**（本库现行规格 ✓）：`1206 → 0805 → 0603 → 0402 → 0201 → 01005`
   ⇒ **一次只降一档** ✓，降完**重新走线** ✓；还不行再降下一档 ✓。
   - **手工焊接**的板：**不低于 0402** ✓；
   - **机器贴**的板：可到 **0201** ✓；
   - **01005** 仅在明确需要时用 ✓。
3. ★★ **例外：电源 / 去耦电容默认不降** ✗ ——
   它们不只是"占位" ✓：容值、**ESR**、**直流偏压下的有效容值（DC bias derating ✓）** 都会随封装变小而变差 ✓
   ⇒ 要降**必须单独确认**（谁降、降到哪一档、为什么 ✓）。
   ✗ 技术上 0402 也有 1 µF/6.3 V ✓（不是"做不到" ✓），**是设计取舍** ✓ ——
   本板 `C2`（电源去耦）按用户意见**保持原规格** ✓，要改会另行提出 ✓。
4. **记录**：降规必须在提交信息/文档里写明「**哪个件、从什么规格到什么规格、为什么**」✓，
   并**重新跑** `pcb_check.py`（⑧ 间隔 / ⑥⑦ 过孔 ✓）与布线 ✓ —— 不许只改不验 ✗。
5. **不许借此掩盖别的问题** ✗：降规是**最后手段** ✓（先试挪位、改走向、加过孔 ✓）；
   若降规只为"让检查过" ✗ 而不是"布线真需要" ✗ ⇒ 退回 ✓。

**机器可查的部分**：`pcb_check.py` 报每个两脚无源件的**焊盘中心距（mm）** ⇒
一眼看出它是 0402 / 0603 / …（标称 land pattern ✓ 见该处注释 ✓）。

## 4. 与布线器共用的口径（防"两套实现找不到原因"）

- **过孔**：`hole size="0.3mm,0.15mm"` ⇒ 铜盘 Ø0.6 / 半径 0.30 ✓
  —— 改尺寸**必须同步**改 `pcb_route.VIA_CLEAR_MM` 与 `pcb_check` 的算法 ✓。
- **线宽**：只能取 Fritzing 下拉里的档位（8/12/16/24/32/48 mil ✓ ⇒ 写 `<wireExtras mils="…">` ✓）；
  仓规 §5b 第 ⑪ 条：**颜色只能用官方配色表** ✓。
  ★ **细间距处要缩宽（neck-down）** ✓：盘与盘的**边缘间隙**放不下「线宽 + 两侧净距」时 ✓
    ⇒ 进该区前把线收到 **10 mil** ✓（`NECK_MIL` ✓，`NECK_ZONE_MM` = 1.5 ✓）。
    判据 = `tight` ✓（`pcb_check.NECK_TRIGGER_MM` = 0.6048 ✓，**单一实现** ✓）：
    `U1`/`D3` 间隙 0.200 ✓、`R1`/`C1`/`J1`/`J2`/`LED2` ≈0.4 ✓ 命中；`C2` 1.5 ✗、`L1` 7.4 ✗ 不命中 ✓。
    为什么必须做 ✗：`VSS` 中心离 `PA2` 盘边只有 0.300 ✓ ⇒ 半宽上限 0.150 ⇒
    **12 mil（0.3048）差 0.0048 mm 也过不去** ✗ ⇒ 只能取 10 mil（0.254 ✓）✓。
- **净空**：铜与铜 **0.15 mm**（`CLEAR_MM` ✓，嘉立创 1 oz 最小线间距 0.127 ✓）；
  过孔与异网焊盘 **0.55 mm**（`VIA_PAD_KEEPOUT_MM` ✓ = **孔心**→盘边 = 铜盘 0.30 + 规则 0.25 ✓）。
- **校验器与布线器各自实现同一规则** ✓（故意的 ✓：互不背书 ⇒ 不会一起错 ✗）。

## 5. 安装孔附近不许布线，更不许穿体（2026-10-01 用户定）

用户原话：「安装孔附近是不能布线的，更不能穿体」✓。

- **判据** ✓：走线 / 过孔 到**孔内壁**的净距 ≥ `HOLE_CLEAR_MM` = **0.25 mm** ✓；
  穿过（净距 < 0 ✓）**必定** FAIL ✗。
- **为什么以前根本没管** ✗：安装孔是 Fritzing **核心孔件**（`HoleModuleID` ✓），
  `hole size="2.2mm,0.0mm"` ⇒ **一点铜也没有** ✗ ⇒ 障碍表里它**不产生任何障碍** ✗、
  ①–⑧ 也没一条看得见它 ✗。实测 `v50H.fzz` 有 **4 根走线直接穿过安装孔** ✗
  （距内壁 −1.100 / −0.900 / −0.800 / −0.300 mm ✓，其中 −1.100 = 正**穿孔心** ✓）。
- **机器守（两道，各自实现 ✓）**：
  - `pcb_check` 第 **⑨** 条 ✓（**圆**的精确判据 ✓，走线用点到线段距离 ✓）；
  - `pcb_route.obstacles()` 把孔按**外接框 + 0.25** 挡 ✓（方框比圆多挡四个角 ⇒ 更严 ✓，代价很小 ✓）。
- **解析只有一份** ✓：`pcb_pads.holes(text)` ✓（`render_pcb.holes_of` 与 `pcb_check.collect` 都调它 ✓）
  —— ✗ 以前只有渲染器会解析 ⇒ 布线器/校验器根本不知道有孔 ✗。
- **孔心 = `<geometry>` + `HOLE_DRAW_OFF_MM`(1.665,1.665)** ✓ —— ✗ 把 `<geometry>` 当孔心会偏 1.67 mm ✗。
